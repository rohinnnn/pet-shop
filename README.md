# PET SHOP — Premium Modern Website

A responsive static website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to https://github.com and create a new **public** repository named `pet-shop`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` (or drag the three files from this folder).
4. Select **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a minute or two. Your website address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/pet-shop/`

## Before using for a real business
- Replace the sample product names, photos and prices with your actual products.
- In `script.js`, replace `hello@example.com` with your shop's real email address.
- The cart is a front-end demo only. Connect a secure order/payment provider before accepting real payments.
- Review image licenses and replace remote sample photos with images you have permission to use.
